2. DATABASE SCHEMA DESIGN (Multi-Tenant Isolation)
--------------------------------------------------------------------------------
We will create a new table `documents` in `backend/models/document.py`:

Table: documents
--------------------------------------------------------------------------------
Column             | Type           | Description
--------------------------------------------------------------------------------
id                 | INTEGER        | Primary Key (auto-incrementing)
user_id            | INTEGER        | Foreign Key -> users.id (Strict tenant isolation)
title              | VARCHAR(255)   | e.g. "10th Standard Secondary Marksheet"
category           | VARCHAR(50)    | "Academic", "Identity", "Financial", "Employment",
                   |                | "Personal", "Healthcare", "Property", "Others"
file_url           | TEXT           | Secure HTTPS URL from Cloudinary CDN
public_id          | VARCHAR(255)   | Cloudinary unique asset ID (used for deletion)
file_type          | VARCHAR(50)    | "application/pdf", "image/png", "image/jpeg"
file_size_bytes    | BIGINT         | Actual file size in bytes (e.g. 1450000 = 1.45 MB)
sha256_hash        | CHAR(64)       | Cryptographic checksum of file bytes for tamper-proofing
is_verified        | BOOLEAN        | Default: True (integrity verified)
created_at         | DATETIME       | Upload timestamp (UTC)
--------------------------------------------------------------------------------
Security Guard: All queries must filter by `WHERE user_id = current_user.id`.
No user can ever read, list, or delete another user's document.

3. BACKEND API ENDPOINTS SPECIFICATION
--------------------------------------------------------------------------------
Module: backend/api/v1/documents.py (Prefix: /api/v1/documents)

1. GET /api/v1/documents/dashboard-stats
   - Purpose: Powers the top 4 stat cards & sidebar storage meter.
   - Response:
     {
       "total_documents": int,
       "storage_used_bytes": int,
       "storage_limit_bytes": 10737418240, // 10 GB in bytes
       "storage_used_formatted": "14.2 MB",
       "storage_percentage": 1.4,
       "shared_links_count": 0,
       "encryption_status": "AES-256 & SHA-256 Active"
     }

2. GET /api/v1/documents/categories-summary
   - Purpose: Powers the 8 category cards with real counts.
   - Response:
     {
       "Academic": 3,
       "Identity": 1,
       "Financial": 0,
       "Employment": 1,
       "Personal": 0,
       "Healthcare": 0,
       "Property": 0,
       "Others": 0
     }

3. GET /api/v1/documents/recent?limit=5
   - Purpose: Powers the Recent Documents table on the Dashboard.
   - Response: List[DocumentResponse] ordered by `created_at DESC`.

4. GET /api/v1/documents
   - Query Params: `?category=Academic&search=degree&page=1&limit=20`
   - Purpose: Full documents repository with search and filter.

5. POST /api/v1/documents/upload
   - Consumes: Multipart form data (file: UploadFile, title: str, category: str)
   - Execution:
     1. Reads file bytes into memory stream.
     2. Computes `hashlib.sha256(bytes).hexdigest()`.
     3. Streams file directly to Cloudinary (folder: `vault/user_{user_id}`).
     4. Saves metadata row into `documents` table linked to `current_user.id`.
     5. Returns new Document object with `file_url` and `sha256_hash`.

6. DELETE /api/v1/documents/{id}
   - Purpose: Deletes asset from Cloudinary and deletes record from database.

4. STORAGE ENGINE ADAPTER PATTERN (Cloudinary -> S3 Ready)
--------------------------------------------------------------------------------
Architecture Pattern: Storage Service Abstraction
File: `backend/core/storage.py`

Interface:
  - `upload_file(file_bytes, filename, folder) -> { url, public_id, size }`
  - `delete_file(public_id) -> bool`

Implementation:
  - Phase 1: `CloudinaryStorage` using `cloudinary` Python SDK.
    Free tier credentials added to `backend/.env`:
      CLOUDINARY_CLOUD_NAME=...
      CLOUDINARY_API_KEY=...
      CLOUDINARY_API_SECRET=...
  - Phase 2 (Scale): Swap implementation to `S3Storage` / `CloudflareR2`
    without touching any API route or model code!
